# スクリーンショット

詳細ページ用の画面写真の置き場所です。初版では撮影していません(公開前に撮影する)。

## 撮影予定

| ファイル名           | 画面                                 | 状態                                                        |
| -------------------- | ------------------------------------ | ----------------------------------------------------------- |
| `home.png`           | ホーム(`/`)                          | 管理者、1440×900。種類別の在庫・要対応・最近の履歴          |
| `ledger.png`         | 台帳(`/items`)                       | 管理者、1440×900、全件・既定の列                            |
| `import.png`         | CSV 取込(`/import`)                  | 取込可・要確認・不可が混ざったファイルのプレビュー          |
| `register-issue.png` | 物品を登録                           | 「登録と同時に支給する」を開いた状態                        |
| `member.png`         | 社員ページ(`/members/sample-suzuki`) | 交換中(支給中 3 点 / 返却待ち 1 点)                         |
| `me.png`             | 自分のページ(`/me`)                  | 一般の社員(`/__keelson/dev` で「(サンプル)佐藤」に切り替え) |
| `issue-dialog.png`   | 支給ダイアログ                       | 台帳の未割当の行から開いた状態                              |
| `mobile-me.png`      | 自分のページ(390×844)                | 一般の社員                                                  |

## 撮り方

1. `local.db` を消して `pnpm dev` を起動する(サンプルが新しく入る)
2. 上記の画面を開き、ブラウザの幅を合わせて撮影する
3. ローカルプレビューの黒い帯が写る場合は、撮影用に `pnpm build && pnpm start` で起動し、
   ブラウザ拡張などで信頼ヘッダ(`X-Keelson-User-Id` / `X-Keelson-User-App-Perms`)を付けて開く
