# 初期値とサンプルデータ

- `masters.json` は**初期設定**です。アプリの起動時に、種類・使用場所の一覧がまだ空のときだけ入ります
  (デプロイしたアプリにも入ります)。
- それ以外は**ローカル開発(`pnpm dev`)とテスト・画面写真の撮影専用のサンプル**です。`pnpm dev` が、
  ローカルのデータベースに物品が 1 件も無いときに入れます。デプロイしたアプリと `pnpm start` には入りません。

日付は「何日前」の相対値で持ち、投入した日を基準に計算するので、いつ入れても最近の記録に見えます。

| ファイル           | 内容                                                                                                                                                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `masters.json`     | 種類と使用場所の初期値(初期設定。デプロイしたアプリにも入る)                                                                                                                                                       |
| `dev-users.json`   | ローカルの名簿(`keelson dev serve` と SDK のローカルモードの形)。`pnpm dev` でログインする人と社員の一覧になる。先頭の管理者(`view,manage`)が既定の利用者で、ほかは一般の社員(`view`)。DB に社員としては保存しない |
| `items.json`       | 物品。`admin` は記録上の操作者(サンプルの総務担当。名簿の先頭の管理者と同じ人)                                                                                                                                     |
| `assignments.json` | 現在と過去の割当。`returnedDaysAgo` があれば返却済み、`replacedByTag` は交換で返却待ちになっている旧品。`former` は記録だけに登場する退職者(名簿に入れないので「メンバー外」になる)                                |

## サンプルの筋書き

- 社員 9 人(表示名は「(サンプル)姓」)と、退職してメンバー外になった 1 人(小林)。
- **(サンプル)佐藤**: PC・マウス・カード・社用携帯に加え、在宅用モニターを持つ(オフィス用と在宅用の使い分け)。
- **(サンプル)鈴木**: PC の交換中。新しい開発用 PC(PC-0006)を 3 日前に受け取り、旧 PC(PC-0004)は
  データ移行後に返却予定の「返却待ち」。
- **(サンプル)伊藤**: 出張用の貸出 PC(PC-0011)の返却予定日を過ぎている(返却期限超過)。
- **(サンプル)中村**: 支給中のセキュリティカードを紛失(利用停止: 紛失、割当は残ったまま)。
- **(サンプル)田中**: PC を入れ替えた履歴と、管理者が回収したマウスの履歴がある。
- **(サンプル)小林**(退職者): PC・カード・社用携帯を 120 日前に回収済み。社員別一覧で「メンバー外」と表示される。
- 未割当の予備品(マウス・キーボード・モニター・カード・ヘッドセット)と、修理中の PC・画面割れの社用携帯。

本物らしい日本語のデータにすること(「test」「あああ」は使わない)。
メールアドレスは予約済みドメイン `example.com` を使う。
